# 결정 사항 (Architecture Decision Records)

아키텍처 결정 사항을 기록합니다. 각 결정은 하나의 파일로 관리합니다.

## 구조

각 결정은 번호와 주제로 구분합니다:

- `001-role-separation.md` - 역할 분배 결정
- `002-build-strategy.md` - 빌드 전략 결정
- `003-testing-approach.md` - 테스트 접근 방식 결정
- `004-communication-protocol.md` - 서버 간 통신 프로토콜 결정

## 작성 가이드

각 결정 파일은 다음 구조를 따릅니다:

```markdown
# [번호] [결정 제목]

## 상태
[제안됨 | 승인됨 | 거부됨 | 보류됨]

## 맥락
[이 결정이 필요한 배경/상황]

## 결정
[내린 결정 내용]

## 결과
[이 결정으로 인한 결과/영향]

## 대안
[고려했던 다른 옵션들]

## 참고
[관련 문서/링크]
```
