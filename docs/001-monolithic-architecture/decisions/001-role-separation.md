# 001 역할 분배 결정

## 상태
승인됨

## 맥락

모노리식 아키텍처에서 AI 로직과 백엔드 로직이 섞여 있어, 포팅 시 역할 분배가 애매한 상황. 확장성과 관리성을 위해 명확한 역할 분리가 필요함.

## 결정

**opencv, GPU 관련 배열 계산** 등은 **AI 서버로 분리**하고, 비즈니스 로직과 API 처리는 **백엔드 서버**에서 담당.

## 결과

* AI 서버와 백엔드 서버 간 명확한 책임 분리
* 각 서버의 독립적인 스케일링 가능
* 기술 스택 선택의 자유도 증가 (AI 서버는 ML 라이브러리 중심, 백엔드는 웹 프레임워크 중심)

## 대안

1. **현재 상태 유지** - 거부: 확장성과 관리성 문제 지속
2. **마이크로서비스로 더 세분화** - 보류: 초기 단계에서는 과도한 복잡도
