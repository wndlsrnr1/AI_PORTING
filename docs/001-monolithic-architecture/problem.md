# 모노리식 아키텍처 문제점

## 문제 정의

클라우드에 AI 프로젝트를 backend/DB/AI module 까지 스파게티 해 놓은 프로젝트를
확장성/관리성/자원 분배 효율을 위해 분리하려는 이슈에 대한 정리

## 문제 상황 정리
- 포팅 시, 특정 라이브러리 종속 기능이 AI에 있어야 할지 백엔드에 있어야 할지 기준
- AI 컨텍스트가 관리 문제로 문제를 정의하고 단위를 지정 해야 하나 기초 지식이 모자라 단위를 지정하기 어렵고 단위 테스트 산정이 어려움
- 용량이 너무 커서 LOCAL 환경에서 AI 관련 로직을 빌드하기 힘듬
- 이와 비슷한 문제로 DOCKER 로 빌드 하기 힘듬
- 범 프로젝트와 관련된 문제라서 테스트 기준을 정의하기 힘듬
- 손용휘 버러지가 view에 스파게티로 코드 모두 몰아 넣어서 디버깅 및 로직 분리가 힘듬
- 개별 단위 프로젝트보다 전체 프로젝트 단위를 고려하며 분리해야 하는 상황임
- 실제로 프로젝트가 실행 되는지 그리고 기능이 돌아가는지도 체크하기 힘듬. 
- nginx, fastAPI, Django의 uvicorn의 기능, Pytorch 종속성에 대해서 이해도가 떨어지고, python의 자원 관리 메커니즘 gpu 관리 메커니즘, 멀티프로세싱에 대해서 이해가 필요함
- 단위 프로젝트가 아니라 전체 프로젝트에 대한 성공 실패 여부가 필요해서 테스트 산정기준 모르겠음
- 궁금증: 단위 테스트 도구는 아는데, 전체 프로젝트에 대한 테스트 방법론/표준 또는 이론이 있는지? 또는 이런 일을 뭐라고 부르는지
- 궁금증: 프로젝트를 나누는 과정에서 인터페이스 수준 종속성을 가진 코드가 없어서 로직 이해가 부분적으로 필요해 보임. 이에 대한 가이드나 해결 바방법

## 해결 전략

### 역할 분배 (backend ↔ AI)

- opencv, GPU 관련 배열 계산 등은 AI 서버로 분리

### AI 컨텍스트 부족 → 단위 작업 산정

- 내 파이프라인을 먼저 정의해서 컨텍스트를 아낌
- 큰 단위 흐름: 프로젝트 빌딩 → 로직 옮기기로 나눔
- 빌딩 단계에서 독립적으로 존재 가능한 목표 단위를 먼저 정의하고 작업을 쪼갬
- 작업 정의는 AI가 구체화 도와줄 수 있으나 프로젝트 지식은 내가 책임. 내가 이해 못하면 AI 지시도 막힘

### 빌딩 과정 세분화

- 종속성/환경 설정 후 프로젝트 빌드
- 각 프로젝트 실행 확인
- 실행 후 이미지 빌딩 확인
- 이후 Docker Compose로 전체 올림
- 전체가 올라온 뒤 서버 간 연결 확인:
  - Redis로 AI 서버 ↔ 백엔드 통신
  - 미디어 서버 경유 AI ↔ 백엔드 통신
  - 3계층(HTTP) 기반 백엔드 ↔ AI 통신

### 로컬 실행·테스트 전략

- 각 프로젝트 로컬 단독 실행에 집중
- 이후 엔드포인트별로 로직 분리 + 테스트 케이스 작성
- 이 단계에서 python 프롬프트/역할 분리 필요
- AI가 낼 법한 실수를 미리 명시해 예방
- 새 로직/과도한 최적화 금지, depth만 적당히 분리하고 복붙 수준으로 구현

### 포팅 단계 프롬프트 흐름

1. 프로젝트 개별 실행
2. 도커 빌드
3. 각 프로젝트 실행 확인
4. 엔드포인트 이관용 프롬프트 작성
5. 엔드포인트별 로직 작성
   - 이관 전 통합 테스트 작성 → 이관 후 동일 테스트로 성공 확인

## 기술 이슈 및 대응

### 용량/빌드 이슈 대응

- 로컬 NVIDIA 로직 불가: 퇴근 전에 빌드 걸어두는 전략
- Compose 빌드 불가: 먼저 Dockerfile로 개별 이미지 빌드 확인, 이전 이미지 정리 후 Compose 빌드로 종합 확인

### 레거시 난해 로직 대응

- 최대한 리팩토링 없이 래핑해서 옮기고, 전체 테스트 통과 후 리팩토링

## 운영 및 학습

### 운영 단위

- 단일(하위) 프로젝트만 올리는 게 아니라, 상위 단위에서 프로젝트들을 로드해 작업
  - 예: docker compose 혹은 프로젝트 묶음 단위

### 기술 이해도 보완

- FastAPI/uvicorn 자원 가용성은 심층 이슈보단 지속 디버깅/성능관리 영역
- 주요 이슈/CRUD/로직 사용에 대한 간단 튜토리얼+이론은 반드시 확보

### 범프로젝트 테스트/명칭(궁금증 정리)

- 범프로젝트 테스트 방법론/표준 여부 확인 필요
- (가설) DevOps? 운영체제 레벨 bash 스크립트? 용어와 방식 추가 조사

### 인터페이스/종속성 가이드(궁금증2)

- 프로젝트 분할 시 인터페이스 단위 종속성이 없어 이관에 로직 이해 필수로 보임
- 업계 가이드 존재 여부 검색 필요
