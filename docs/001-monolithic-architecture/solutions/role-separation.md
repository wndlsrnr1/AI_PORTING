# 역할 분배 해결 방안

## 문제

포팅 시, 특정 라이브러리 종속 기능이 **AI에 있어야 할지** **백엔드에 있어야 할지** 애매함.

## 해결 방안

### 기준 설정

* **opencv, GPU 관련 배열 계산** 등은 **AI 서버로 분리**
* 비즈니스 로직, API 엔드포인트는 **백엔드 서버**에 유지
* 데이터베이스 쿼리, 캐싱은 **백엔드 서버** 담당

### 분리 원칙

1. GPU/ML 연산이 필요한 모든 로직 → AI 서버
2. HTTP 요청 처리, 인증, 권한 → 백엔드 서버
3. 데이터 영속성, 트랜잭션 → 백엔드 서버

## 구현 단계

1. 현재 코드베이스에서 AI 관련 로직 식별
2. 의존성 분석 (어떤 라이브러리가 어디에 필요한지)
3. 인터페이스 정의 (AI 서버와 백엔드 간 통신 방식)
4. 단계적 이관 (한 번에 다 옮기지 않고 단계적으로)

## 참고사항

* 초기에는 **복붙 수준**으로 구현하여 동작 확인 우선
* 리팩토링은 전체 테스트 통과 후 진행
